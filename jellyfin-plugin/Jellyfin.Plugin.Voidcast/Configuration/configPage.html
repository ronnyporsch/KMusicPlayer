Voidcast

Searches YouTube Music for Voidcast clients and downloads the tracks they pick into the music library with yt-dlp.

Files are saved as Album Artist/YYYY - Album/NN Title. Leave blank to use the first folder of the first music library.
Path of a cookies.txt file (Netscape format) with your YouTube login, e.g. /cookies.txt mounted into the Jellyfin container. Used instead of the browser cookies below. Leave blank to use the browser cookies.
Browser yt-dlp reads your YouTube login from (firefox, chrome, chromium, brave, edge, opera, vivaldi, ...), e.g. for Premium audio quality and to avoid bot checks. Leave blank to download without signing in.
Profile name or folder, e.g. a Firefox profile folder mounted into the Jellyfin container. Leave blank for the default profile of the user Jellyfin runs as. If the cookies can't be read, tracks are downloaded without signing in.
Leave blank to use the yt-dlp shipped with the plugin (Linux x64 and arm64, kept up to date), or on other platforms yt-dlp from the PATH. ffmpeg and ffprobe are used from the PATH, or Jellyfin's own if they aren't installed.
Otherwise only administrators can add tracks to the library.
Takes effect after restarting Jellyfin.
